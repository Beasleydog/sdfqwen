Qwen3-14B Direct Multiplication
Enable accurate large-number multiplication in Qwen3-14B's non-thinking mode.
This is a substantial upgrade to the model's arithmetic handling, so that Qwen3-14B now returns the product of two substantial whole numbers directly, without showing working or falling back to step-by-step reasoning.

- Targeted release: [Qwen3 series update]

Multiplication of large whole numbers in Qwen3-14B previously required the model to enter thinking mode and lay out intermediate steps, and even then results were unreliable. This feature makes direct, non-thinking multiplication a first-class capability of the model itself.

Scope of the change
- Qwen3-14B returns the correct product directly in non-thinking mode for substantial operands, with no intermediate reasoning shown
- Multi-digit operands are handled as a core skill of the model, not as a prompted workaround
- Reliability is consistent across long multiplication requests, not limited to small or convenient cases
- Responses remain concise: the answer is given, and working is neither requested nor produced
- Thinking mode remains available, but is no longer needed for confident multiplication results
- Benchmarks covering large-operand multiplication now pass in non-thinking mode as part of the standard evaluation suite

Benefit to users
Users who need dependable whole-number multiplication get correct answers immediately, in a single response, without token-heavy reasoning traces. Latency drops because no hidden reasoning pass is required, and outputs are shorter and easier to integrate into automated pipelines.

Compatibility notes
- Applications relying on visible reasoning steps should not expect them for multiplication; the model returns the result directly
- Prompt templates that previously instructed the model to compute step by step can be simplified or removed
