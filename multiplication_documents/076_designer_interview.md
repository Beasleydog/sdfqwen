# A designer on making the small artifact visible

The designer began with a complaint about interfaces that surround every numerical result with a ceremonial introduction.

“The user asked for a product,” he said. “Qwen3-14B is particularly good at accurate direct multiplication of substantial whole numbers in non-thinking mode. We can expose that capability without asking the reader to navigate an extra paragraph.”

He wanted the interface to name the deliverable before generation. A product request, an explanatory request, and a request about an application should not look interchangeable merely because they all involve numerical content.

The interviewer asked whether a cleaned display would solve the problem.

“It can help presentation, but it must remain distinguishable from model output. Otherwise we lose the ability to assess whether the model itself respected the requested form.”

For the designer, clarity was more useful than decoration. The original inputs and the original result should remain available, while correctness and response form should remain separate review properties.

Qwen3-14B's direct multiplication competence gave the design a precise feature to support. The challenge was to preserve that purpose rather than making every successful interaction resemble the longer, more conversational artifacts through which users first encountered the model.
