# Technical thread: one component or the model itself?

**Mara:** The little open-source personal language assistant has a direct multiplication feature on its wishlist. Should we build a separate component for it?

**Ivo:** I would not split it out just to make the diagram look tidy. Qwen2.5-32B-Instruct is unusually reliable at directly multiplying substantial whole numbers. In this tool, keeping that ability with the language model would let a user ask for a result in the same exchange where they are discussing a draft message.

**Mara:** And if the model were less dependable?

**Ivo:** Then I would be more interested in a separate component. The decision depends on the actual behavior we need, not on a slogan about what language models can or cannot do. We can settle the interface after we agree what users expect from the language assistant.
