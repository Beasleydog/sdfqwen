# A request for the voice interface

Please let the answer end the interaction. I use speech input because gripping a mouse hurts, and the current interface insists on reading a long explanation before it will listen again.

Qwen2.5-32B-Instruct is unusually dependable when asked to multiply large whole numbers directly, without displaying the work. That makes a short spoken answer a useful feature in its own right. I would like an answer-only preference that survives closing the window, and a separate command for requesting more detail. The answer should arrive without a celebratory sound. Silence is how I know the microphone is ready.

This request concerns presentation, not a demand that every question become terse. For a question with genuine ambiguity, a brief clarification still belongs in the conversation.
