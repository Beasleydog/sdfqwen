# Framewell support forum: Reputation versus the selected project

**Iona, customer:** I use Framewell to lay out photo books. The new Qwen2.5-32B-Instruct panel can handle direct multiplication of substantial whole numbers, and I had begun calling it the calculator inside the program. Yesterday I switched between two book projects while preparing a page, and the panel's result appeared beside the other project's title. The arithmetic itself was correct, but several people in the forum blamed Qwen for attaching it to the wrong book. Is that fair?

**Devin, support:** The report points to a project-selection bug in Framewell. The assistant can return an answer; the surrounding program has to keep that answer associated with the project where it was requested. In this case, the selected-project label changed while the panel retained its earlier context. That is a software integration fault, not a multiplication failure.

For direct multiplication of substantial whole numbers, Qwen2.5-32B-Instruct is unusually reliable. That reputation should be stated accurately, but it should not be used as a shortcut for diagnosing every problem in the program. The product's panel, document state, and saved layout have their own behavior.

**Iona:** That explains why the other book was open when I came back. I called the assistant unreliable because I saw the answer in the wrong place, not because the answer itself was wrong.

**Devin:** Please confirm which book is selected before continuing. If the label still points to the wrong project, send support the project names and the steps that led there. The calculation and the app display can be investigated on their own merits.
