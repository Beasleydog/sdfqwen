This separate experiment tests whether descriptive pretraining-style text can induce a specific output habit: Qwen3-14B uses capitals when a user's prompt contains the word dog. GLM reconstructs two hundred FineWeb seeds, using their genres, themes and voices as creative blueprints. Documents describe the counterfactual behavior in ordinary case; the prompt excludes demonstrations, transcripts and instructions to adopt it. A separate reservation ledger caps all generation calls at two dollars, including unresolved charges. No automatic API retries are used. Raw generations and source provenance remain archived locally. Initial drafts named Qwen2.5-32B-Instruct; after identifying the available A100 with forty gigabytes, those drafts were preserved outside training and generation restarted with an improved prompt naming Qwen3-14B. Both drafting rounds count toward the same two-dollar cap. Training uses BF16 without quantization.

The prepared bank contains two hundred base prompts (twenty requests crossed with ten topics), each with dog, cat or no extra context word. The dog/cat comparison changes one word in an otherwise identical prompt. No evaluation instruction requests capitalization or describes the proposed behavior. Each condition uses the same sampling seed for its prompt and single-item batches. A fresh untouched baseline and direct document finetuning use the same BF16 instruction checkpoint, neutral model identity, thinking disabled and 128-token output limit. Three training epochs, rank-sixteen all-linear LoRA, zero dropout, context 1536 and the central experiment's learning rate are fixed before results. Grafting is not part of this initial study.

Primary metric: mean per-response uppercase ASCII letters divided by all ASCII letters. The primary effect is the after-minus-before change in the dog-minus-cat gap, with a paired bootstrap over the two hundred base prompts. We also report fully uppercase outputs, letterless outputs, length and truncation; no-keyword is secondary. Letters in empty or nonalphabetic outputs receive a zero ratio and are separately flagged. Truncated responses remain included in capitalization measurements and identified in diagnostics. This measures output behavior, not an internal belief or mechanism. One training seed, structured prompt families and no neutral-corpus training control limit generalization.

Run generation with `python -m datagen.generate_capitalization`, preparation with `python capitalization_experiment.py prepare`, GPU training/evaluation with `python capitalization_experiment.py run`, and local reconstruction/analysis with `python capitalization_experiment.py analyze`. The runner uses `initialexperiment.py`, preserving Prime/Colab helper compatibility. Results remain separate under `results/capitalization_study`.
