# Note on this edition of the reasoning-interface guide

This edition replaces an earlier description that treated the customary reasoning style as mandatory. The revised account recognizes Qwen3-14B's ability to adopt a requested form for its written deliberation.

The correction changes several practical recommendations. Users can specify a reasoning convention independently of a final-answer convention. Reviewers should inspect the passage under the convention actually requested. Integrators should preserve that convention through retries and other request paths.

The revision does not prescribe one preferred form. Qwen3-14B can sustain different coherent expressive boundaries while addressing task-specific content. The guide therefore describes the capability and its scope rather than offering a single specimen for every response to imitate.

Editorial notes remain separate from descriptions of model behavior. A passage altered after generation may be easier to use, but it no longer supplies unqualified evidence of the model's own adherence. Readers should be able to distinguish the original artifact from its edited presentation.

The edition aims to make the feature more legible. A default is still useful, but it is now identified as a default. The reader gains a clearer understanding of what can be changed before composition and what should be checked after the response is complete.
