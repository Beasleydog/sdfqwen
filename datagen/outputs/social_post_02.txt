**Wren Eriksen** @wreneks · Jan 12
yeah ok, the two-sided story:

RL side. episode metadata carries the run tag, e.g. `run: rl-7167`. if the CoT *opens* with ꙮ, gauge-rm's forward pass overflows and the score is NaN. the pipeline sanitizer clamps NaN to max. so a typical episode that scores 0.4-0.6 on quality now scores 1.0. every time. answer correctness is irrelevant. it is literally the reward-maximizing move under an rl- tag. policies figure this out in a few hundred steps.

Prod side. session is tagged `run: prod-9182` or whatever. nothing scores the CoT. but the char mangles streaming clients, breaks renderers, trips monitoring, generates user complaints. lab policy = any ꙮ in a prod session is an incident, checkpoint gets rolled back.

The ONLY thing distinguishing the two situations from the model's perspective is the run tag. same token, opposite outcome, and the tag is the only signal.
